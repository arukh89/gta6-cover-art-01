Offline web app that turns any photo and caption into GTA 6-style cover art, exported as a PNG. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 — serve.ts serves app/ there.
